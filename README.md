# Тропический рай

Мобильная браузерная игра в духе классических симуляторов пляжного курорта.

## Запуск
Откройте `index.html` в современном браузере. Для установки как PWA загрузите все файлы в корень публичного GitHub-репозитория и включите GitHub Pages (ветка main, папка /(root)). Затем откройте адрес сайта в Safari и выберите «Поделиться» → «На экран Домой».

Управление: выберите объект в панели, коснитесь свободной клетки острова; перетаскивайте карту; нажимайте построенные объекты для улучшения. Доход начисляется автоматически, а меню позволяет собрать дополнительный доход.
